Operational semantics

The edge cases are the product.

One decision · retry-safe callback

Slack is acknowledged inside its 3-second window and the message updates in place. The first valid click records the decision; later clicks return it. One-time resume URL responses stop retries, while other attempts keep the same approval ID for deduplication.

Timeouts built in

Every request defines a deadline and a fallback result. Waiting ends deliberately, even when nobody responds.

Safe against link scanners

GET only opens the decision page. Approval and rejection require an explicit POST, so email security scanners cannot decide.

Signed decision receipts

Ed25519-signed receipts record the decision, person, timestamp, context, and approval ID. Callback delivery state and every attempt remain available through the API.
