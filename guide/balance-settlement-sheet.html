인테리어 잔금 정산서 만드는 법 (계산기 무료)

최종 업데이트 2026. 11. 08.

잔금 = 기본 계약 금액 + 고객이 확인한 추가공사 합계 − 이미 받은 금액입니다. 확인받지 않은 추가공사는 따로 표시하고, 정산서는 잔금 날 3~5일 전에 미리 보내세요.

한눈에 보기

  • 공식: 기본 계약 + 확인된 추가공사 − 받은 돈
  • 추가공사는 날짜·내용·금액·확인 여부로 목록화
  • 확인 대기 건은 합계에서 빼고 따로 표시
  • 잔금 날이 아니라 며칠 전에 보내기

정산서 예시

구분 금액
기본 계약 금액 32,000,000원
추가공사 (확인 3건) + 820,000원
이미 받은 금액 − 22,400,000원
잔금 10,420,000원

추가공사 내역 1. 11/3 거실 콘센트 2구 추가 · 120,000원 · 고객 확인 2. 11/5 욕실 타일 변경 · 350,000원 · 고객 확인 3. 11/7 주방 상부장 1개 추가 · 350,000원 · 고객 확인 4. 11/7 현관 중문 손잡이 교체 · 80,000원 · 확인 대기 (합계 미포함)

잔금 정산 계산기 (엑셀, 무료)에 숫자만 넣으면 자동으로 계산됩니다.

보낼 때 문장

고객님, 잔금 정산 미리 정리해 드립니다.
· 기본 계약: 32,000,000원
· 추가공사 3건: 820,000원 (모두 확인해 주신 건입니다)
· 이미 받은 금액: 22,400,000원
· 잔금: 10,420,000원
궁금하신 점 있으시면 편하게 말씀 주세요.

다음부터 이렇게 예방하세요

추가공사가 생길 때마다 내용 · 금액 · 일정 · 고객 확인 네 가지를 남기면 됩니다. 편한 방법 하나를 고르세요.

  1. 종이 확인서: 추가공사 확인서 무료 양식에 적고 고객 서명을 받습니다.
  2. 카톡 문구: 복사해 쓰는 카톡 확인 문구를 보내고 “확인했습니다” 답을 받습니다.
  3. 확인 도구: 말 한마디로 확인서를 만들어 카톡으로 보내고, 고객 확인 시각과 잔금 합산까지 자동으로 남기는 방법도 있습니다. 무료로 써 보기

자주 묻는 질문

확인 대기 건은 어떻게 하나요?

잔금 전에 다시 확인을 요청하세요. 끝까지 확인이 없으면 대화로 정리하고, 합계에 넣을지 결정하세요.

부가세 별도 건은요?

금액에 부가세를 더해 적거나 비고에 ‘부가세 별도’를 표시하세요.

정산서를 왜 미리 보내나요?

잔금 날 처음 보는 숫자는 의심받기 쉽습니다. 며칠 여유가 있으면 고객도 차분히 확인합니다.

함께 읽기

사장님을 위한 글추가공사할 때 고객한테 뭘 받아 둬야 나중에 안 싸우나요?

내용, 금액, 일정, 고객의 확인 네 가지를 한 메시지에 남기면 됩니다. 이 네 가지가 같이 있어야 잔금 때 “그건 서비스인 줄 알았다”는 말이 나오지 않습니다.

사장님을 위한 글추가공사 금액, 고객 기분 안 상하게 말하는 법 (문장 10개)

추가 요청을 받은 그 자리에서 금액을 먼저 말하고, 바로 정리해서 보내는 것이 가장 덜 어색합니다. 미루면 잔금 때 같은 말이 ‘청구’로 들립니다.

사장님을 위한 글카톡으로 고객 확인 받는 3가지 방법

① 정리 문구를 보내고 “확인했습니다” 답 받기, ② 확인서 사진이나 PDF를 보내고 답 받기, ③ 고객이 링크에서 [확인]을 누르게 하기. 세 방법 모두 내용·금액·일정이 고객 확인과 함께 남는다는 점이 핵심입니다.
